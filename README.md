# VKINHA (VKx)

A next-gen built on **BNB Smart Chain (BSC)** with deflationary mechanics, liquidity auto-management, and multi-chain compatibility (EVM networks).

---

## 🔧 Technology Stack
- **Blockchain**: BNB Smart Chain + EVM-compatible chains  
- **Smart Contracts**: Solidity ^0.8.18 (OpenZeppelin-based, custom burn + liquidity logic)  
- **Frontend**: React + ethers.js (planned)  
- **Development**: Hardhat, OpenZeppelin libraries  
- **Router/DEX**: PancakeSwap V2 (0x10ED43C718714eb63d5aA57B78B54704E256024E)

## ✨ Features
- 🔥 **Deflationary Mechanics**:  
  - Automatic burns from reserve supply  
  - Time-based burn multipliers (35% on fees in first 4 days, 2% lifetime)  
- 💧 **Auto Liquidity**:  
  - Swap & liquify mechanism with PancakeSwap  
  - Controlled LP recipient  
- 🛡️ **Fair & Secure**:  
  - Max buy/sell fee capped at 7.8%  
  - Fees can be permanently frozen  
- 👥 **Controllers & Ownership**:  
  - Dual-controller system (controller1 & controller2)  
  - Project & Dev wallets with transparent allocation  
- 🌍 **Multi-chain Ready**:  
  - Built for BSC, but fully EVM-compatible for expansion to Ethereum, Arbitrum, Base, Polygon, etc.
